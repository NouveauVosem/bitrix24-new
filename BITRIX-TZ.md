# ТЗ для разработчика CRM (crm.alvla.eu): поиск и карточка компании для «Кристалла»

## Зачем

Эндпоинты нужны в двух местах «Кристалла»:

1. **Дела.** При назначении дела менеджер выбирает компанию: это автодополнение по мере ввода,
   поэтому ответ должен быть быстрым.
2. **ИИ-чат.** Это инструмент (tool) модели. Пользователь пишет, например, «что у нас с INTEAL?»,
   модель сначала ищет компанию (п. 1), потом берёт её полную карточку (п. 2) и отвечает по ней.
   Модели нужен структурированный JSON без HTML и лишнего.

Оба эндпоинта делаются в том же стиле и в той же папке, что и существующие
`https://crm.alvla.eu/local/ajax/crystal/...` (например `crystal/stats/deals_search.php`).

## Общие требования

- GET, параметр `token`, как в существующих эндпоинтах.
- Ошибка: JSON `{ "error": "текст" }` с кодом 4xx/5xx, не HTML. Если компания не найдена,
  ответ 404 с `{ "error": "not found" }`.
- Даты: `YYYY-MM-DD HH:MM:SS`, в корне ответа пояс `"tz": "Europe/Kyiv"`.
- Деньги: число и код валюты отдельными полями (`opportunity`, `currency`).
- Телефоны: `value` содержит только цифры с кодом страны (`420777123456`), `raw` хранит номер в исходном виде.
- Ответственный: `assigned_by_id` (ID пользователя Битрикса) и `assigned_by_name`.
- Текстовые поля (комментарии) обрезать до 2000 символов и убирать из них HTML и BB-коды.

## 1. Поиск компаний: `crystal/clients/companies_search.php`

Параметры:
- `q`: часть названия, ИНН/VAT, email, домена сайта или телефона (от 2 символов).
  Регистр, лишние пробелы, кавычки и организационно-правовую форму (`SA`, `s.r.o.`, `GmbH`,
  `ООО` и т. п.) игнорировать: ИИ может написать название не так, как оно записано в CRM;
- `assigned_by_id`: только компании этого ответственного, необязательный;
- `ids`: список id через запятую, вернуть именно эти компании (нужно, чтобы обновлять подписи);
- `limit`: по умолчанию 20, максимум 100;
- `offset`.

Ответ:

```json
{
  "items": [
    {
      "id": 123,
      "title": "INTEAL SA",
      "full_title": "INTEAL Société Anonyme",
      "country": "FR",
      "city": "Lyon",
      "vat": "FR123...",
      "assigned_by_id": 15,
      "assigned_by_name": "Сергей Иванов",
      "phones": [{ "value": "33...", "raw": "+33 ...", "type": "WORK" }],
      "emails": ["info@inteal.fr"],
      "web": ["inteal.fr"],
      "last_deal_date": "2026-10-02",
      "open_deals": 2,
      "match": "title|phone|email|vat|web"
    }
  ],
  "total": 1,
  "next_offset": null
}
```

- `match` показывает, по какому полю нашлась компания.
- По телефону сравнивать нормализованные цифры, хотя бы последние 9.

Сортировка: сначала точное совпадение, потом совпадение с началом названия, потом по `last_deal_date`, новые первыми.

## 2. Карточка компании: `crystal/clients/company.php?id=`

Отдаёт всё, что известно о компании, одним запросом: ИИ-чат передаёт этот ответ модели целиком.

Параметры:
- `id`: ID компании, обязательный;
- `assigned_by_id`: необязательный. Если передан, а ответственный компании другой, ответ
  403 `{ "error": "not your company" }`. Так менеджер в ИИ-чате видит карточки только своих компаний.

```json
{
  "tz": "Europe/Kyiv",
  "id": 123,
  "title": "INTEAL SA",
  "full_title": "INTEAL Société Anonyme",
  "company_type": "CUSTOMER",
  "industry": "...",
  "country": "FR", "city": "Lyon", "address": "...",
  "vat": "...", "reg_number": "...",
  "assigned_by_id": 15, "assigned_by_name": "Сергей Иванов",
  "phones": [...], "emails": [...], "web": [...],
  "comments": "текст из поля комментария",
  "created": "...", "modified": "...",
  "contacts": [
    {
      "id": 77, "full_name": "Jean Dupont",
      "post": "Purchasing manager",
      "phones": [...], "emails": [...]
    }
  ],
  "deals": {
    "open": 2, "won": 14, "lost": 3,
    "last_date": "2026-10-02",
    "won_sum": [{ "currency": "EUR", "opportunity": 125000 }],
    "recent": [
      {
        "id": 555, "title": "...",
        "stage_name": "...", "stage_semantic": "open|won|lost",
        "opportunity": 12000, "currency": "EUR",
        "assigned_by_name": "...", "created": "...", "close_date": "..."
      }
    ]
  },
  "last_activity": {
    "type": "CALL|EMAIL|MEETING|COMMENT|...",
    "subject": "...",
    "author_name": "...",
    "created": "..."
  },
  "uf": {
    "UF_CRM_...": { "title": "Подпись поля", "value": "..." }
  }
}
```

- `deals.recent`: последние 10 сделок, новые первыми.
- `last_activity`: последнее дело или комментарий таймлайна по компании, `null`, если их нет.
- `uf`: пользовательские поля компании с подписями. Пустые поля не отдавать. Значения
  списков отдавать текстом (подписью), а не id варианта.

## Как проверить

Для каждого эндпоинта пришлите пример запроса и ответа на реальной компании (например, INTEAL SA)
и время ответа. Проверьте поиск по `inteal`, `Inteal S.A.`, номеру телефона в любом формате и домену.

Время ответа: п. 1 не больше 300 мс, п. 2 не больше 2 с.
